# Challenge 00: Introduction to GitHub Copilot (Read Only)

### Estimated Duration: 20 Minutes

>**Note:** This challenge is for read-only purposes and exploration only.

GitHub Copilot is an AI coding assistant that helps you write code faster and with less effort. Then, you can focus more energy on problem solving and collaboration.

Research has found that GitHub Copilot helps developers code faster, focus on solving bigger problems, stay in the flow longer, and feel more fulfilled with their work.

### GitHub Copilot Features

You can use Copilot to:

- Get code suggestions as you type in your IDE.
- Chat with Copilot to get help with your code.
- Ask for help using the command line.
- Organize and share context with Copilot Spaces to get more relevant answers.
- Generate descriptions of changes in a pull request.
- Research, plan, make code changes, and create pull requests for you to review. Available in Copilot Pro+, Copilot Business, and Copilot Enterprise only.
- Use Copilot in the following places:

Your IDE:

- GitHub Mobile, as a chat interface
- Windows Terminal Canary, through the Terminal Chat interface
- The command line, through the GitHub CLI
- The GitHub website

## Plans for GitHub Copilot

GitHub offers several plans for GitHub Copilot, depending on your needs and whether you're using Copilot as an individual or as part of an organization or enterprise.

- **GitHub Copilot Free** is available to individual developers who don't have access to Copilot through an organization or enterprise. This free plan includes limited access to select Copilot features, allowing you to try AI-powered coding assistance at no cost.

- **GitHub Copilot Student** is available to verified students. The plan includes unlimited completions, access to premium models in Copilot Chat, access to Copilot cloud agent, and a monthly allowance of premium requests.

- **GitHub Copilot Pro** is designed for individuals who want more flexibility. This paid plan includes unlimited completions, access to premium models in Copilot Chat, access to Copilot cloud agent, and a monthly allowance of premium requests. Verified teachers, and maintainers of popular open source projects may be eligible for free access.

- **GitHub Copilot Pro+** includes, in addition to everything in Copilot Pro, a larger allowance of premium requests, and full access to all available models in Copilot Chat. Ideal for AI power users who want access to the most advanced capabilities.

- **GitHub Copilot Business** is for organizations on GitHub Free or GitHub Team plan, or enterprises on GitHub Enterprise Cloud. This plan includes Copilot cloud agent and enables centralized management and Copilot policy control for organization members.

- **GitHub Copilot Enterprise** is for enterprises using GitHub Enterprise Cloud. It includes all the features of Copilot Business, plus additional enterprise-grade capabilities. Enterprise owners can assign Copilot Enterprise or Copilot Business to individual organizations, or assign Copilot Business directly to users and teams.

## Enabling GitHub Copilot Enterprise

To use GitHub Copilot Enterprise features, your GitHub Enterprise Cloud account must have an active **GitHub Copilot Enterprise** subscription.

Access to GitHub Copilot is managed at both the **enterprise** and **organization** levels:

- **Enterprise owners** can enable GitHub Copilot access for selected or all organizations within the enterprise.
- **Organization owners** within enabled organizations can assign GitHub Copilot Enterprise licenses to individual users or groups within their organization.

Once GitHub Copilot access is enabled, administrators can configure additional Copilot capabilities and policies, including features available on GitHub.com and supported IDEs.

### Feature and Policy Management

GitHub Copilot features can be managed at the enterprise or organization level:

- **Enterprise owners** can enforce organization-wide policies for Copilot features across the enterprise.
- Alternatively, enterprise owners can allow individual organizations to manage their own Copilot feature settings.
- If permitted by enterprise policy, **organization owners** can independently enable or disable specific GitHub Copilot features for their organization.

### Commonly Managed Features

Administrators can configure settings for features such as:

- GitHub Copilot Chat
- Code completion suggestions
- Copilot on GitHub.com
- Public code filtering
- Model access and policy controls
- IDE integrations
- Repository indexing and contextual assistance (Enterprise)

This structure allows organizations to maintain governance, compliance, and security controls while enabling AI-assisted development capabilities across teams.
